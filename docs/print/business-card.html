Printing these cards

This file is the single source of the business card. The ready-to-print PDFs live in public/downloads/ — silicortex-business-card-en.pdf and silicortex-business-card-ar.pdf, each two pages at exactly 85 × 55 mm (page 1 front, page 2 back), plus -light variants on white. The same files are offered for download on the website's contact page, in the visitor's language.

  • After editing this file: run npm run cards:build from the repo root and commit public/downloads. The site refuses to build while the PDFs are older than this source, so a card change cannot go live without the download changing too.
  • Print shop: send the PDF as-is and ask for duplex printing at 85×55 mm. A matte or soft-touch laminate suits the dark card; ask about spot UV on the logo if you want a premium finish.
  • Pre-cut card stock at home: print at actual size / 100%, never "fit to page".
  • The QR code links to https://www.silicortex.de — test it with a phone camera before a print run.
